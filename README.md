# Copilot
I'm tired of only helping when I'm told what to do

# The Problem
One parent tracks everything: doctor appointments, outgrown shoes, upcoming school events. The other parent wants to help but is always one step behind, waiting to be told what needs doing.
The real issue isn't forgetting tasks—it's not knowing what to think about proactively. Not having the mental model that lets you see what's coming.

# The Solution
For the primary planner: A zero-friction brain dump. Text or voice. No organizing required.
For the other parent: A daily 2-minute digest showing what's on the radar, with enough context to start informed conversations.
The goal: After a few weeks, you start anticipating needs without the app. You become a proactive co-planner, not just a helpful executor.

# Why I'm Building This
I'm the less-informed parent. My wife carries the full mental load, and I'm tired of only being reactive. This is my attempt to build the mental models she already has—and learn to build AI-powered apps in the process.
If this resonates, follow along. If it works, I'll open-source it.
